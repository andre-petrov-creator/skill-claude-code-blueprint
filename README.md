Blueprint für neue Claude-Code-Projekte: Projektbeschreibung + Implementierungsplan.

## Installation (automatische Updates)
In Claude Code:

    /plugin marketplace add andre-petrov-creator/skill-claude-code-blueprint
    /plugin install claude-code-blueprint@skill-claude-code-blueprint

Danach unter `/plugin` → Marketplaces → `skill-claude-code-blueprint` das **Auto-Update einschalten**.

Dieses Repo ist ein automatisch erzeugter Spiegel. Änderungen nur im Quell-Repo.
